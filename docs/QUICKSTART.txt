СИМУЛЯТОР ЭКЗАМЕНА — ОГЭ ПО ИНФОРМАТИКЕ
Версия 1.4.0 / Linux x86_64 / целевая ОС: MOS

1. Откройте архив в Ark и распакуйте его целиком в любую папку.
2. В распакованной папке дважды щёлкните «Установить».
   Если MOS спросит, что сделать с файлом, выберите «Выполнить».
   В окне установщика нажмите «Установить», затем «Запустить».
3. В меню приложений и на рабочем столе появится «Симулятор экзамена ОГЭ».
   Для следующих запусков дважды щёлкните ярлык на рабочем столе.
   Откроется установленный браузер или отдельное окно на его основе.
   Интернет не нужен. Python, Node.js и npm устанавливать не требуется.
4. Для проверки выберите демонстрационный экзамен.
   Код: DEMO-2026. Введите ВЫМЫШЛЕННЫЕ регистрационные данные.
5. В заданиях нажимайте «Сохранить ответ». Прикрепление файла само по себе
   не означает сдачу ответа: после выбора также нажмите «Сохранить ответ».
6. Завершение — кнопкой с подтверждением либо автоматически через 150 минут.
   Папка и ZIP результата создаются автоматически; кнопка скачивания —
   только дополнительная копия.

Терминал и sudo не нужны. Установка выполняется только текущему пользователю
в ~/.local/opt/oge-exam-simulator/. Распакованную папку после установки
можно удалить: ярлыки работают из установленной копии.
Для обновления распакуйте новый архив и снова откройте «Установить».
Данные экзамена и результаты сохраняются отдельно и не заменяются установкой.
Для пробы без установки можно дважды щёлкнуть «Запустить» в распакованной папке.

Обычное расположение данных:
      ~/.local/share/oge-exam-simulator/
Сеансы: подпапка sessions.
Результаты: Документы → Симулятор экзамена → Результаты.
Кнопка «Результаты» на главной требует входа учителя и открывает эту папку.
После открытия режим учителя закрывается. После завершения
«Открыть папку» открывает отдельный результат. Старые результаты
автоматически копируются сюда; прежние ZIP сохраняются без изменений.

Если браузер не открылся, откройте файл OPEN-IN-BROWSER.html в папке данных,
пока приложение работает. Не передавайте этот файл другим: он содержит ключ.
Если политика школьного браузера блокирует локальный адрес, обратитесь
к администратору. Программа не меняет политики безопасности браузера.

Закрытие окна браузера НЕ ставит время на паузу и НЕ завершает локальный
процесс. Повторный запуск ярлыка открывает тот же сеанс. Кнопка питания
в шапке завершает приложение; время экзамена продолжает учитываться при
следующем запуске. Выключенный компьютер не может сформировать ZIP:
в этом случае автоматическое завершение происходит при следующем запуске.

ВАЖНО: итоговые файлы НЕ зашифрованы и содержат паспортные данные.
Не публикуйте их в GitHub. Для тренировок используйте вымышленные данные.

Сборка проверена на виртуальной МОС Desktop 12 (MOS-V 260926), Chromium 151:
16 заданий, восстановление после перезапусков и итоговый ZIP.
Физический школьный компьютер и полный реальный 150-минутный сеанс
ещё требуют отдельной проверки.
Требуются Linux x86_64, glibc >= 2.28, libstdc++ с GLIBCXX_3.4.21 и браузер.
Это учебный симулятор, не официальное экзаменационное ПО и не система оценки.

Автопроверка для учителя необязательна: в редакторе откройте «Автопроверка»
и задайте ответы, текстовый эталон, запуски Python 3 / JavaScript
или критерии таблиц ODS/XLSX и презентаций ODP/PPTX.
Все строки входных данных одного запуска вводятся в одно поле.
Можно включить «Эталонная программа», вставить код или открыть .py/.js,
выбрать язык отдельно и нажать «Проверить эталон». Ручной ожидаемый вывод
можно оставить в отдельных тестах. Файлы, которые читает программа,
добавляйте в «Исходные файлы» задания; в 15–16 они необязательны.
Код эталона не добавляйте туда: исходные файлы передаются ученикам.
Сохраните проект себе; ученику передайте «Экспорт экзамена» без эталонов.
Затем откройте проект → «Проверить работу» → ZIP ученика → «Проверить».
Проверка программ использует изоляцию MOS; при её отсутствии код не запускается.

Перед передачей общего компьютера ученику один раз откройте редактор и задайте
пароль учителя (от 10 символов). Он защищает проект и эталоны; сохранить его
нужно отдельно, восстановления нет. На главную и замок закрывают режим учителя.
После перезапуска и через 15 минут потребуется повторный вход.
Сохранённый проект .oge зашифрован этим паролем; опубликованный экзамен
для ученика не содержит эталонов и не требует пароля учителя.
Старые внешние проекты и скачанные отчёты оставляйте только у учителя.
