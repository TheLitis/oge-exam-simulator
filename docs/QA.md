## Исправленные ошибки

1. Проверки одного PID было недостаточно после аварии или перезагрузки: старый PID мог принадлежать другому процессу. Перед повторным открытием проверяется авторизованный health сервиса; при неопределённом ответе второй таймер не запускается.
2. Найденный при утрате конфигурации сеанс не записывал свой ID обратно. После завершения и следующего запуска результат мог исчезнуть с экрана. Восстановление теперь сохраняет ID в конфигурации; полный путь проверен на MOS.
3. Поле кода активации вызывало предложение Chromium сохранить пароль с паспортным номером как логином. Код теперь вводится в обычное текстовое поле без автозаполнения; повторная активация проверена в отдельной папке данных.
4. WHPX зависал на мягкой перезагрузке UEFI с `Unexpected VP exit code 4` после штатного отключения файловых систем MOS. Добавлена команда штатного выключения и холодного запуска; Installed+WHPX использует поддерживаемый `reboot=shutdown`. Проверены оба пути, включая запрос перезагрузки из гостевой ОС и последующий запуск. Это обход ограничения виртуализации; команда описана в [MOS-TESTBED.md](MOS-TESTBED.md).
