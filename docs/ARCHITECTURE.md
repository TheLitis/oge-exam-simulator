# Архитектура

## Компоненты

- `src/io.cjs`: закрытые локальные каталоги, атомарный JSON, безопасный ограниченный импорт .oge, ZIP-экспорт, SHA-256.
- `src/model.cjs`: неизменная матрица 16 заданий / 9000 секунд, регистрация, хеширование кода, проверка манифеста и файлов.
- `src/service.cjs`: редактор, импорт, активация, снимок варианта, сеанс, сохранение, часы, восстановление, результаты.
- `src/server.cjs`: только loopback HTTP, случайный ключ, разрешённые маршруты, очередь мутаций и системный запуск браузера.
- `ui/views.js`: экранированные HTML-компоненты для главной, регистрации, ученика, редактора и результата.
- `ui/app.js`: взаимодействия, диалоги, выбор файлов, работа с API, черновики, обновление таймера, Blob-скачивание.
- `ui/style.css`: локальный адаптивный интерфейс без внешних шрифтов и CDN.

## Состояния

`нет сеанса -> регистрация + верный код -> active -> finished`

Переход `finished -> active` в рамках того же сеанса запрещён. При новом запуске экзамена создаётся новый UUID и отдельная папка. Метаданные, снимок условий и копии прикреплённых файлов хранятся отдельно от оригиналов. Последовательная очередь операций предотвращает одновременную перезапись состояния. Перед записью нового ответа повторно проверяется срок.

Черновик текста и выбранный файл сохраняются отдельно от подтверждённого ответа. Завершение сначала фиксирует неизменяемый статус и причину, затем создаёт отчёт и ZIP. Ошибка экспорта не удаляет сеанс и допускает повторную упаковку. JSON меняется в памяти только после успешной записи на диск.

## Время

Во время работы используется максимум из прошедшего настенного времени, монотонного времени процесса и записанного нижнего предела. Резервная точка сохраняется каждые 5 секунд; пользовательские записи также обновляют время. После перезапуска сохраняется исходный срок. Никакой клиентский JavaScript не задаёт длительность и не может сохранить ответ после срока через штатный API.

При выключенном компьютере/завершённом процессе выполнение невозможно: просроченный сеанс завершается при следующем запуске. Для защиты от администратора ОС или редактирования локального файла требуется другая доверенная инфраструктура, которой здесь нет.

## Формат .oge

Обычный ZIP только с `manifest.json` и файлами `assets/<uuid>.<ext>`. Исходные материалы хранятся с расширением `.bin`, оригинальные имена — в манифесте. Манифест задаёт format/version/id/title/published/durationSeconds/activation/tasks. Тип ответа вычисляется из номера задания, не доверяется входному пакету. Продолжительность всегда 9000 секунд. Изображения сортируются простым сравнением имён, без localeCompare и numeric-sort.

Собственные ограничения на ZIP исключают произвольные пути, архивы с симлинками, ZIP64, шифрование, многотомность и неограниченную распаковку. Формат .oge не предназначен для импорта любых ZIP с произвольной структурой. ZIP, выдаваемый ученику как материал к заданию, напротив, хранится как непрозрачный исходный файл: приложение его не распаковывает.
