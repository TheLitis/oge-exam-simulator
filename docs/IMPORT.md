# Перенос проекта из ChatGPT

10 октября 2026 года проект из разговора [«Разработка симулятора экзамена»](https://chatgpt.com/c/6ac9371a-bcb8-83ed-8c31-cfe73a6709d9) перенесён в `C:\Users\loval\Documents\ChatGPT\Sim`.

## Что перенесено

В корне находятся все исходники, интерфейс, тесты, документация, примеры экзамена, условия и материалы из `oge-exam-source.zip`. Все 54 записи архива сверены побайтово по SHA-256 до добавления сведений о переносе. Из `repository.bundle` восстановлена ветка `main` и оба исходных коммита:

- `582572f` — приложение, редактор, восстановление сеансов и Linux-сборка;
- `9bdf238` — протокол проверки интерфейса и переносимой поставки.

Оригинальные вложения и сохранённая переписка лежат в `imported/chatgpt/`:

- `oge-exam-source.zip`;
- `oge-exam-simulator-linux-x64.tar.gz`;
- `oge-exam-checksums.txt`;
- `README.md`, `QA.md`, `MOS-CHECKLIST.md`;
- `oge-editor-screen.png`;
- `oge-student-screen.png` — оригинальные байты встроенного снимка ученика; имя дано при переносе;
- `conversation.md` и `conversation.json` — доступная переписка целиком;
- `transfer-manifest.json` — состав, размеры, SHA-256 и сведения о проверках.

Linux-пакет также распакован в `imported/linux/oge-exam-simulator-linux-x64/`. Для переноса на MOS используйте оригинальный `.tar.gz`: он сохраняет права запуска Linux-файлов. Архивы, runtime и снимки переписки исключены из индекса Git, но сохранены в рабочей папке. Исходная Git-история и код доступны в основном репозитории.

## Что изучено

Исходное задание: графический симулятор ОГЭ по информатике с 16 заданиями, переходом к любому номеру, явным сохранением каждого ответа, регистрацией ученика и кодом активации. Задания 1–12 принимают краткий ответ, 13–16 — файл; материалы для скачивания предусмотрены в 11–14. Время экзамена — 150 минут, завершение вручную требует подтверждения, по сроку происходит автоматически. Ответы и файлы должны сохраняться вместе.

Редактор импортирует изображения по схеме `номер задания.номер изображения`, распределяет их по заданиям и показывает несколько изображений вертикально в лексикографическом порядке (`1.1.png`, `1.10.png`, `1.2.png`). Целевая платформа — MOS ОС; готовая поставка должна работать без установленного Python.

Реализация: локальный HTTP-сервис на Node.js, интерфейс на HTML/CSS/JavaScript, встроенная JSZip и переносимая Linux-сборка со своим Node.js. Основные модули описаны в `docs/ARCHITECTURE.md`. Установка npm-зависимостей для исходников не требуется. При переносе код приложения не изменялся.

## Проверки переноса

- SHA-256 обоих архивов совпал с исходным `oge-exam-checksums.txt`.
- Все 54 файла исходного ZIP восстановлены без изменения содержимого.
- Все 49 файлов из внутреннего `SHA256SUMS.txt` Linux-пакета совпали.
- Отдельные README, QA и MOS-CHECKLIST совпали с документами в исходниках.
- `npm.cmd run check`: синтаксис 12 JavaScript-файлов проверен.
- `npm.cmd test`: 42 теста прошли, ошибок и пропусков нет.

Проверки выполнены на Windows с Node.js `v24.20.0`. При извлечении Windows tar исказил кириллическое имя `НАЧАТЬ-ЗДЕСЬ.txt`; правильное имя восстановлено после идентификации файла по SHA-256. Содержимое файла и оригинальный архив не изменились.

При переносе запуск на MOS ОС ещё не был проверен. Затем подготовлен [виртуальный стенд МОС Desktop 12](MOS-TESTBED.md): на нём подтверждены запуск Linux-сборки и 42 теста. Последующие проверки, полный экзамен, установка, ночная тема и перенос результатов описаны в [QA](QA.md). В исходной переписке публикация на GitHub оставалась незавершённой; на момент восстановления у локального репозитория не было remote.
